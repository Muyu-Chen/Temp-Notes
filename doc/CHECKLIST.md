# ✅ 项目完成清单与质量标准 (Checklist & Quality Standards)

本文档列出了 **Temp Notes** 已实现的核心功能及其质量验收标准。

---

## 🛠️ 核心功能实现状态

### 1. 草稿管理 (Draft)
- [x] **自动保存**: 250ms 防抖保存至 IndexedDB。
- [x] **新建草稿**: 支持保存当前更改或丢弃后新建。
- [x] **清空草稿**: 针对未存档内容提供二次确认。
- [x] **状态反馈**: 实时显示“保存中/已保存”状态。

### 2. 条目存档 (Archive)
- [x] **存档逻辑**: 自动识别重复内容，更新现有条目或创建新条目。
- [x] **Markdown 预览**: 实时切换编辑与预览模式，并持久化选择。
- [x] **加密保护**: AES 对称加密笔记内容与标题。
- [x] **录音附件**: 支持本地录制、回放、重命名及随笔记存档。

### 3. 数据管理 (Data)
- [x] **搜索系统**: 毫秒级全文检索。
- [x] **回收站**: 删除条目后进入回收站，支持恢复或永久删除。
- [x] **自动清理**: 可配置回收站自动清理周期（7/30/90天）。
- [x] **导入导出**: 支持 ZIP 完整备份（含录音）及单条 TXT/MD 导出。

### 4. 增强功能 (Advanced)
- [x] **主题系统**: 深色/浅色模式无缝切换。
- [x] **设置中心**: 调整字体大小、配置 LLM 接口。
- [x] **AI 增强**: 可选的标签生成功能。

---

## 🌟 质量保证标准 (Quality Standards)

### 1. 架构合规性
- [ ] 遵循分层设计，业务逻辑与 UI 操作完全解耦。
- [ ] 模块间通过依赖注入进行通信，无全局污染。

### 2. 性能表现
- [ ] 应用启动时间 (Lighthouse 指标) < 1s。
- [ ] 搜索 1000+ 条目时无明显卡顿。
- [ ] 录音处理不阻塞主线程。

### 3. 兼容性
- [ ] 适配桌面端与主流移动端浏览器。
- [ ] IndexedDB 存储异常处理完备（如隐私模式下的降级提示）。

### 4. 隐私安全
- [ ] 默认完全离线运行。
- [ ] 加密笔记在存储介质中不泄露任何明文信息。
