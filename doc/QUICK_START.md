# 🚀 快速开始指南 (Quick Start Guide)

欢迎使用 **Temp Notes**！本文档将帮助你在 5 分钟内掌握本应用的核心功能。

## 🛠️ 如何运行

1.  克隆或下载本项目。
2.  在浏览器中打开根目录下的 `index.html`。
    *   *推荐*: 使用 VS Code 的 "Live Server" 扩展或通过 `python -m http.server` 运行，以获得最佳的模块化加载体验。

---

## ✍️ 核心工作流

### 1. 草稿区 (Draft Area)
*   **自动保存**: 你在左侧输入框输入的任何内容都会每 250ms 自动保存。
*   **存档**: 按 `Ctrl + S` 或点击“存档”按钮，将当前草稿保存到右侧的条目列表。
*   **清空**: 按 `Ctrl + L` 或点击“清空”，清空当前草稿。

### 2. 条目管理 (Item Management)
*   **加载**: 点击右侧列表中的条目，将其内容恢复到草稿区。
*   **搜索**: 按 `Ctrl + K` 或使用搜索框，实时检索所有已存档的条目。
*   **删除**: 点击条目上的删除按钮，条目将进入回收站。

### 3. 加密保护 (Encryption)
*   点击“更多”菜单中的加密选项，为你的笔记设置密码。
*   默认密码为 `password`，支持自动解密。

---

## ⌨️ 快捷键速查 (Shortcuts)

| 快捷键 | 功能 |
| :--- | :--- |
| `Ctrl + S` | 存档当前草稿 (Archive Draft) |
| `Ctrl + K` | 聚焦搜索框 (Search Items) |
| `Ctrl + L` | 清空当前草稿 (Clear Draft) |

---

## 🎙️ 录音与附件

*   支持在草稿中添加录音。
*   存档时，录音将随笔记一同保存。
*   支持重命名和导出录音文件。

---

## 💾 数据备份与迁移

*   **ZIP 导出**: 一键备份所有笔记和录音。
*   **ZIP 导入**: 轻松从备份文件恢复数据。
*   **TXT/MD 导出**: 支持单条笔记导出为文本或 Markdown 文件。

---

## 🌓 主题切换

点击页面右上角的太阳/月亮图标，在**明亮模式**和**深色模式**之间切换。系统会自动记住你的选择。

---

## 🚨 常见问题 (FAQ)

**Q: 我的数据存在哪里？**
A: 存储在浏览器的 **IndexedDB** 中。除非你清理浏览器缓存或手动删除，否则数据将永久保留。

**Q: 我可以在手机上使用吗？**
A: 是的，应用采用响应式设计，完美适配移动端浏览器。

**Q: 为什么我无法使用 AI 功能？**
A: 你需要在“设置”中配置你自己的 OpenAI 兼容 API Key 和 Base URL。
